# Novelite TUI

在终端里安静地写作。延续 [Novelite](https://github.com/hirovel/novelite) 的章节组织与写作能力，专注于中文长文、干净排版和可靠保存。

**当前为预览版，提供 macOS Apple Silicon Homebrew 安装包。** 包含作品与卷章管理、双窗格编辑、大纲与目标、搜索替换、历史恢复、中文排版、导入导出及可选专注模式。真实输入法、各终端显示与长文写作手感仍需实际验收。

## macOS 安装与更新

面向 Apple Silicon（M1 及后续芯片）：

```sh
brew install hirovel/tap/novelite-tui
novelite-tui
```

更新由 Homebrew 管理，文稿与个人偏好保留：

```sh
brew update && brew upgrade novelite-tui
```

正文居中，工具按需展开；设置 → 写作 → 专注写作可以临时收起周边界面。字体、光标和背景沿用终端偏好。

## 本地运行

安装 Rust 工具链（项目声明最低 1.89；本地构建使用 1.97），在仓库目录执行：

```sh
cargo run --locked -- path/to/manuscript.md
# 新建作品文件夹（父目录须存在，目标文件夹须不存在）
cargo run --locked -- --new path/to/my-book
# 打开作品
cargo run --locked -- path/to/my-book
# 优化构建
cargo build --locked --release
```

Windows 请在 Windows Terminal 的 PowerShell 标签页中运行 Release 程序。也可以在仓库目录执行以下命令，在新 Windows Terminal 窗口创建作品（`my-book` 须尚不存在）：

```powershell
$repo = (Get-Location).Path
wt -w new --reloadEnvironment -d $repo "$repo\target\release\novelite-tui.exe" --new "$repo\my-book"
# 后续打开同一作品，去掉 --new
wt -w new --reloadEnvironment -d $repo "$repo\target\release\novelite-tui.exe" "$repo\my-book"
```

无路径启动会继续上次文件或作品；首次启动显示开始页，可选择打开或新建作品。最近路径失效时保留记录和失败原因，可选择其他条目继续，不需要退出应用。

字体、字号、光标外观和背景透明度沿用终端偏好，默认前景与背景也跟随终端。应用管理正文宽度、辅助面板和语义高亮；不要求安装特殊图标字体或修改终端配置。默认辅助面板收起，可从设置固定目录和大纲。

## 在 macOS 自用

从完整仓库构建，保留 `vendor/` 和 `Cargo.lock`。在已安装 Rust 工具链及 Apple 命令行工具的 Mac 终端中运行：

```sh
cargo build --locked --release
./target/release/novelite-tui
# 可选：安装到当前用户的 Cargo bin，之后直接运行 novelite-tui
cargo install --path . --locked
novelite-tui ~/Documents/小说.md
```

不需要修改 kitty 的字体或全局键位。F 键被系统占用时，Ctrl+P 和可点击入口仍可打开操作；粘贴可使用终端原生入口。macOS 的中文输入法、系统剪贴板和最终显示仍需实际终端验收；包构建与安装检查不能替代写作手感验证。

## 开始写作

- **F1 / Ctrl+P** 打开底部命令中心，也可点击底部“命令”。首页显示常用操作，输入中文名称即可搜索全部操作；Esc 关闭并回到原位置，正文中的 `/` 正常输入。
- **F4** 打开底部设置。Tab 切换“排版／布局／写作”，上下选择属性，左右或 Enter 调整；正文宽度、分屏、面板和写作辅助都在这里。
- **设置 → 写作 → 专注写作** 临时只显示当前文稿，也可在命令中心搜索“专注”或“禅模式”。底部保留字数和保存状态，点击“退出专注”恢复原窗格与面板；字体和光标继续沿用终端。
- 点击底部 **正文 ▾ → 设为标题**，当前段落变为蓝色粗体标题；**标题 ▾ → 改回正文**，也可撤销。纯文本标记仍可见，长标题折行保持样式。章节标题入口用于修改目录名称，提示会说明正文不替换。
- 在命令中心选择 **打开文件或作品**，可输入现有 TXT、Markdown 或作品文件夹路径，支持 `~/` 主目录和 Tab 补全；选择 **最近文件与作品** 可筛选和切换。上下选择、Enter 或点击打开，Esc 返回。Delete 编辑筛选文字，Ctrl+D 仅移除最近记录，不删除手稿。

开始页可用上下与 Enter 选择，也可点击条目；O 打开、N 新建作品、Esc 退出。路径框的 Tab 只查当前一级目录，循环匹配的文件夹与 TXT/Markdown 文件；没有候选或目录不可读时保留输入并提示。输入框接受终端原生粘贴，系统快捷键是否转交应用由终端决定。

命令查询和单行路径输入都支持左右、Home/End、Delete/Backspace及终端原生粘贴；长输入会随光标水平滚动。正文保留常规编辑操作。以下章节提供快捷键、文件安全和高级功能参考。

## 编辑与作品管理

终端能力可分别降级：`--no-mouse`、`--no-enhanced-keyboard`、`--no-bracketed-paste`，可单独使用或组合。增强键探测在无响应时有限等待后回退到基础按键；不需要焦点事件。自动颜色模式在 `NO_COLOR` 非空或 `TERM=dumb` 时使用单色显示；显式选择颜色模式可覆盖自动策略。无粘贴分隔时，使用 F1 中的 `paste` 命令从系统剪贴板粘贴，避免终端逐键发送多行文本或控制字符；系统剪贴板失败时会显示错误，内部副本可用 `paste-internal`。

正常退出及可处理错误会恢复终端并分别尝试关闭输入报告。强制终止不会执行清理：重新打开终端标签页再启动；不要将强制关闭当作保存操作。Windows 没有 Unix 作业控制式的挂起/恢复，本地预览不声称其他系统的挂起行为已验证。

目标文件的父目录须已存在。新文件默认 UTF-8；已有文件必须为 UTF-8。Markdown 源码原样显示，文件中的终端控制字符以可见字符替代显示。

方向键、Home/End、Backspace/Delete 编辑，Shift+方向键/Home/End 选区，Ctrl+A 全选。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；粘贴分隔事件中的整批文本一次撤销，普通字符事件逐次撤销。Ctrl+S 或 F2 保存，Ctrl+Q 或 F10 保存后退出。停顿约 300ms 或持续输入约 2s 时安排后台保存；界面区分待保存、保存中、已保存与失败。保存失败时保留会话，可重试或从命令面板另存到新路径。关闭终端或强制杀进程可能丢失最后持久化之后的输入，自动保存间隔不是故障时的丢失上限。遇到终端异常，可重新打开终端；Unix 终端也可运行 `reset`。

新作品包含第一卷、第一章。命令 `chapters` 打开目录，输入标题筛选、上下选择、Enter 跳章，Esc 返回正文；选择卷后，`new-chapter` 在该卷新建章节。`new-volume` 新建卷，`rename-volume`/`rename-chapter` 改标题，`previous-chapter`/`next-chapter` 前后跳章。切章保留当前会话的光标、选区与撤销历史；切换前先保存，失败会留在原文稿。标题可以重复，身份和磁盘文件名保持独立。

`chapter-up`/`chapter-down` 调整当前章顺序，`volume-up`/`volume-down` 调整选中卷顺序。`move-chapter`/`copy-chapter` 选择目标卷并放到卷末，复制时输入副本标题；`number-chapters` 显式按目录顺序编号。`recycle-chapter`/`recycle-volume` 先显示删除范围，默认取消，确认后移入回收区；若删除了所有正文，自动留下空白章。`recycle-bin` 选择记录和目标卷恢复到卷末，同名章节并存，可再上下调整顺序。回收区随作品另存，不提供永久清空操作。

`recent-projects` 打开底部最近文件与作品列表，也提供打开与新建入口。Delete 编辑筛选文字，Ctrl+D 只移除所选记录，手稿保留。命令 `open-project` 接受现有 TXT/Markdown 文件或作品文件夹路径；`new-project` 接受尚不存在的作品文件夹路径，`rename-project` 修改当前书名。单篇文件和作品的最近列表、光标位置保存在配置目录的 `recent-projects.json`；可用 `--state path/to/recent.json` 指定独立配置。无路径参数时恢复上次文件或作品；没有记录则显示开始页。旧版作品记录会保留并迁入新格式。损坏、不支持的版本或其他程序改动的记录不会被自动覆盖，界面分别提示最近记录失败与正文保存结果；修复记录后重启重试。记录不能放在作品目录内。

`save-as` 将整个作品复制到新的文件夹并切换过去；单篇文稿则另存为新文件。目标已经存在时拒绝覆盖。第二个实例以只读方式打开作品；若正在提交或恢复，请稍后重开。作品正文与清单通过恢复日志一起提交，格式见 [作品格式](docs/project-format.md)。请在没有应用写入时复制或备份整个作品文件夹。

作品历史独立于自动保存：有编辑时约每 5 分钟、切章或关闭时建立快照；与上一个恢复点内容相同则不重复。`mark-snapshot` 手动标记当前稿，`history` 显示本章历史与容量，Enter 进入只读预览，方向键浏览，Enter 先备份当前稿再恢复，Esc 返回。恢复是可撤销的正文编辑并立即保存；备份失败会保留当前稿并停止恢复。快照校验失败会报错，普通正文保存仍可用。

`history-settings` 输入“近期点数,保留天数,每章容量MiB”，默认 `50,7,256`：保留最近 50 个自动点，并保留最近 7 个 UTC 日期每天至少一个；手动标记点永久保留。超出容量时停止新增快照并提示提高容量，不删除标记点。策略在下一次新快照时执行；历史随整个作品另存。关闭时快照失败会留在会话中，可调整策略或修复磁盘后重试。

当前章节与作品清单约每 500ms 在后台检查外部变化；干净文稿先保留刷新前恢复点，再载入合法内容并尽量保持光标。缓存章节在重新进入时检查。双方同时修改、正文删除或清单无效时显示“外部冲突”，暂停对应保存。`conflicts` 提供载入磁盘、把当前本地稿另存为新文件、备份双方后明确覆盖；覆盖须输入“覆盖”确认。选择前磁盘再次变化则停止，查看后重新选择。`check-external` 可立即检查。

冲突副本保存在作品的 `conflicts/<ID>/`，包含本地正文、可读取的磁盘原始字节与双方清单；若放弃待恢复日志，也先将日志保存在副本中。整部作品另存会携带这些副本。单篇文稿的副本放在同级 `novelite-conflict-<ID>/`。损坏或更高版本清单禁止覆盖，可先另存本地稿。第二实例保持只读；文件锁无法约束其他编辑器，保存前检查也不等于跨应用的原子锁，不承诺任意软件同时写入绝对安全。

F1 或 Ctrl+P 打开底部命令中心；输入中文名称或命令 ID 搜索，方向键选择，Enter 执行，Esc 返回正文。首页只列常用操作，可选择“全部操作”浏览；搜索始终涵盖全部命令。查询中的左右/Home/End只移动输入光标，不重置结果选择。面板显示当前配置的快捷键。增强键盘无响应时使用基础键盘路径。

`split-right`／`split-down` 打开左右／上下双窗格，默认对照同一章；从章节目录选择章节只改变当前窗格。F6 或 `focus-other-pane` 切换焦点，也可点击另一侧正文；`swap-panes` 交换位置，`close-pane` 关闭当前窗格并回到另一侧。单篇文件也可同文对照。每个窗格保留自己的光标、选区和滚动位置；同章共用正文及撤销历史，撤销提示指出目标章节。

异章切焦点沿用切章保存边界：先保存离开的章节，失败则保持原焦点与文稿，可重试或整书另存。手动保存／退出时，另一章已在离开时完成保存，当前章仍须完成保存才能退出。关闭窗格不清空章节历史。空间不足时只显示活动窗格，F6 仍可切换隐藏窗格；扩大后恢复原方向和焦点。工程起点为每窗格至少 40 列、10 行正文，另预留标题及分隔。

正文支持点击定位、拖选、滚轮与越界拖选滚动，按软换行后的字素和屏幕列宽定位。鼠标报告默认启用，可用 `--no-mouse` 启动，或通过 `toggle-mouse` 切换。应用选区用于下述复制命令；终端自身的选区由终端管理，应用不能读取。关闭应用鼠标后可用终端原生选择与复制，某些终端也提供按住 Shift 的绕过方式。没有鼠标事件时仍可用方向键和 Shift 选区。

Ctrl+F 或 `find` 查找当前章节的文字；底栏显示章节、修订、匹配数量与上下文，正文仍可编辑。F3／Shift+F3 或 `find-next`／`find-previous` 循环跳转，Esc 或 `close-find` 关闭查找栏。`find-toggle-case` 切换区分／忽略大小写，初始区分；忽略模式逐字符转 Unicode 小写，不做语言区域折叠或规范化。只匹配完整字素，支持空格，标点按原文匹配。

`replace-current` 替换选中的匹配，`replace-all` 替换当前章节全部不重叠匹配；输入空文本可删除，Esc 取消。整章替换一次撤销，同章另一窗格的位置按每处修改映射。正文变化后旧结果显示过期，下次跳转／替换重新查询；已打开的替换输入若遇到修订、章节或单次替换选区变化，会停止并要求重新选择。切到其他章节需重新查找。所有入口也可在 F1 命令面板找到并改键。

Ctrl+Shift+F 或 `search-book` 搜索作品目录中的章节标题与正文，使用区分大小写的文字匹配。活动稿及未保存稿使用查询时的会话版本，其余正文在后台读取；结果按目录顺序列出章节、匹配数、上下文和版本。↑↓ 选择、Enter 在活动窗格跳转；文稿变化时重新查询并要求重新选择，不沿用旧位置。读取失败会显示错误及其余可用结果。结果最多展示前 1000 条，计数仍覆盖全书，可缩小查询范围。

F7 或 `focus-book-search` 在全书结果和正文间切换，搜索时仍可写作、保存。新查询替换旧任务；结果面板中的 Esc 或 `close-book-search` 关闭并取消任务，恢复有效的来源面板。正在进行的文件读取返回后，后台任务检查取消标记并丢弃结果；关闭不等待磁盘读取。切换作品或另存时清理原查询。全书搜索与章节替换分开。

章节和搜索面板可通过 F1 中的 `pin-chapters`、`pin-search` 固定或收起；`chapters-left/right/wider/narrower` 和 `search-left/right/wider/narrower` 调整左右位置及宽度（18–60 列）。`toggle-chapters-module`、`toggle-search-module` 开关模块；关闭搜索会取消后台查询，保存与历史恢复仍可用。点击面板行可打开章节或搜索结果，点击正文或执行 `focus-editor` 返回编辑。

布局默认保存在配置目录的 `workspace.json`，可用 `--layout path/to/workspace.json` 指定独立路径。模块开关与固定、位置、宽度在重启后恢复，输入焦点不自动抢回。窗口不足以保留 40 列正文和 10 行高度时临时隐藏固定面板；主动打开的面板覆盖显示，Esc 返回。扩大窗口恢复原布局，缩窗不会改写偏好。配置无效时提示并保留原文件，写入失败时保持之前的布局。

`style-reading`（默认阅读感）、`style-terminal`（跟随终端）、`style-compact`（紧凑工作台）分别提供自适应居中正文、少量边距、充分使用宽度的工作区。阅读感默认使用可用宽度的80%，上限92列；F4的“排版”可选择更宽或铺满。风格单独记在 `workspace.json` 的 `appearance` 中，切换保留布局、焦点、选区和编辑历史。空间紧张时优先去掉装饰留白，再临时收起辅助区或另一窗格。

默认使用终端前景、背景和色板；需要自定义外观时，可在命令中心搜索主题或背景。`terminal-defaults` 恢复跟随终端，`background-terminal/light/dark` 选择背景，`color-auto/basic/mono/truecolor` 选择颜色能力。自动模式在非空 `NO_COLOR` 或 `TERM=dumb` 时使用单色；Windows Terminal会话标记、kitty/WezTerm标记或 `COLORTERM=truecolor/24bit` 可启用真彩色，否则采用基础色。显式颜色选择覆盖自动判断。标题通常使用终端蓝色色槽，单色时仍加粗；终端自定义色板会影响实际颜色。设置中的动效只作用于可见颜色变化，不移动正文或光标。保存和退出快捷键在底部工具区内也可用。

Ctrl+C／X／V 分别执行系统复制、剪切、粘贴，也可从 F1 找到 `copy`、`cut`、`paste`，键位可自定义。系统剪贴板在后台串行操作，页脚显示实际结果；失败剪切保留正文，失败粘贴不替换为旧内部内容。`copy-internal`、`cut-internal`、`paste-internal` 显式使用本次会话内部副本。系统写入失败时选区也保留为内部副本。含 NUL 的复制会明确拒绝系统写入，避免平台截断。

等待系统结果时可以继续写作；位置、选区、章节或正文已改变时不自动粘贴／剪切，读取到的文本留在内部剪贴板。未完成操作会提示稍后退出，`cancel-clipboard` 可放弃结果并退出。Linux 剪贴板依赖可用的 X11／Wayland 会话，远程或受限环境失败时使用终端原生粘贴或内部操作；退出应用后系统能否保留复制内容取决于剪贴板管理器。

支持粘贴分隔的终端会将一批文本作为一次可撤销插入；控制字符仅作为文稿内容保存，屏幕显示安全替代符，不执行命令。未提供粘贴分隔的终端只能按普通输入接收原生粘贴，不能保证整批撤销，夹带控制按键也无法与快捷键可靠区分；需要完整保留这类素材时使用系统 `paste` 命令或文件导入。

键位配置是 JSON 文件，Windows 默认 `%APPDATA%/novelite-tui/keymap.json`，macOS/Linux 默认 `$XDG_CONFIG_HOME/novelite-tui/keymap.json`（未设置时为 `~/.config/novelite-tui/keymap.json`）。也可用 `cargo run --locked -- manuscript.md --keymap path/to/keymap.json` 指定；父目录可手动创建，关闭应用后编辑，重开加载。例如：

```json
{"F6": "save", "Ctrl+Alt+q": "quit"}
```

命令 ID 包括 `save`、`save-as`、`rename-project`、`quit`、`undo`、`redo`、`select-all`、`reset-keys`。配置覆盖默认映射；F1、Ctrl+P 保留为命令入口，Esc 保留为关闭／取消操作。快捷键支持 F2–F12 或 Ctrl/Alt 与英文字母组合，可加 Shift。格式、命令或键位冲突会显示提示并回退默认；面板中的“恢复默认键位”会保存空配置。键位文件应位于作品文件夹之外，不能指定为当前文稿。

```sh
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```

非交互 stdin/stdout 拒绝进入全屏且不写文件；`--help` 和 `--version` 可重定向。依赖版本由 `Cargo.lock` 固定，界面使用 Ratatui 0.30.2 与 Crossterm 0.29.0。

编辑按 Unicode 字素处理（含 emoji 组合与 CRLF），软换行和选区按终端列宽定位，显示变化不写入正文。Crossterm 的本地源码副本修复 Windows Alt-code 文本事件，许可证及修改范围见 [第三方声明](THIRD_PARTY_NOTICES.md)。只测工作区编辑与布局的微基准可运行 `cargo run --locked --release --example edit_latency`；它不代表屏幕显示延迟。

## 大纲与写作进度

F1 → `planning` 打开当前章的大纲与目标面板。`edit-outline` 进入多行大纲编辑：Enter 换行，方向键和 Shift 选区，撤销/重做、系统或内部复制粘贴、鼠标定位与拖选均可用。保存键（默认 Ctrl+S / F2）确认并保存，Esc 放弃本次草稿；退出会先确认大纲。停用模块也会保留有效草稿。大纲只写入作品元数据，不混入正文。编辑期间章节或元数据被其他入口改变时拒绝旧提交，保留草稿供复制或取消。

`chapter-goal`、`book-goal` 设置非负整数字数目标，0 清除目标。`pin-planning` 固定面板，`planning-left/right/wider/narrower` 调整位置和宽度，`toggle-planning-module` 开关大纲和统计；设置沿用工作区布局记忆。

状态行显示本章、全书字数及目标；其他操作提示临时占用状态行时，可在大纲面板查看进度。正文编辑、替换与撤销增量更新本章计数；全书只统计在用章节，排除回收区、大纲、章名与目标。首次打开或结构变动后在后台统计，读取不完整时显示待统计或错误，不把缺失章节当成零字。`refresh-word-counts` 重新读取非活动章节，适合外部工具修改后更新全书进度。活动稿和后续修订优先于旧后台结果；停用会取消后续读取，正在执行的单次磁盘读取返回后丢弃旧结果。

计数沿用桌面版 `countWordsFast`：基本区汉字（U+4E00–9FFF、U+3400–4DBF、U+F900–FAFF）及「〇」逐字计，连续 ASCII 字母、数字、下划线计一个词，其余字符分隔但不计数。扩展区汉字如「𠀀」、emoji 不计；带音调字母不作为 ASCII 词的一部分，组合符会分隔词。这是现有桌面口径的兼容选择，不代表完整 Unicode 语言学分词。`中文 Hello world 123 abc_def` 为 6，`A中文B` 为 4，`foo-bar don't 3.14` 为 6；Markdown 标点不计，标记内文字照常统计。

## 中文排版与输入配对


F1 中的 `format-paragraphs`（两格全角缩进与空行整理）、`remove-indents`（顶格）、`clean-punctuation`（中文标点）、`pangu-spacing`（中英文/数字间距）只处理当前章。确认框显示目标章名，Enter 执行，Esc 取消。实际改变正文前先写入历史恢复点；写入失败保留原稿。每次排版可用一次撤销恢复，确认期间切章或正文变动则拒绝旧请求。整章排版需要作品文件夹；单篇文稿须先迁入作品，才能建立持久恢复点。

段落与标点口径参考桌面版：两格全角缩进、连续空行合并，普通小说章标题顶格；中文邻接的逗号、句号、冒号、分号转全角，感叹号/问号及括号转中文形式，连续短横线、波浪线和省略号归一，直引号逐段配对。中英文间距沿用桌面版 U+4E00–9FA5、U+3000–303F 与 ASCII 字母数字的交界规则。以下保留规则优先：保留 LF/CRLF；Markdown 标题、列表、引用、分隔线、表格、链接、含方括号标签或反引号的行不处理，围栏代码块整体原样保留；英文单词内的撇号不改。它是保守的小说源码排版工具，不是 Markdown 解析器，执行后可检查或撤销。

`toggle-pairing` 开关正文输入配对，首次默认关闭。启用后输入 `“ ‘ " ' 《 （ ( 【 [ 「 『 {` 插入对应结束符，选区会被包裹且保持选中；在结束符前输入相同结束符只越过它。空配对中退格一次删除两侧；括号带组合符时及非空内容正常逐字素退格；关闭后退格只删前一个字素。英文单词内的 `'` 不配对。多字提交、分隔粘贴、系统/内部粘贴及语义插入均保持原样，不触发配对或整章排版；保存也不排版。

`toggle-typography-module` 停用整个排版模块，移除其命令并取消待确认操作，正文与历史不变。模块与配对偏好记在工作区配置，跨作品与重启保留。输入法预编辑由终端负责；终端若把一整段提交拆成逐字符事件，应用无法可靠识别来源，可关闭配对。合成输入测试不代表真实中文输入法已经验证。

## 专注写作

F1 命令面板提供 `focus-paragraph`（当前硬换行段落）、`focus-sentence`（当前句子）、`focus-nearby`（当前视觉行及上下各一行）和 `focus-off`。句子按 `。！？!?….` 分隔，连续句末标点与结束引号留在前句；这是一种轻量文本规则，不进行语法分析。软换行不改变段落，聚焦以各窗格自己的光标为准。单色终端使用加粗与暗显区分重点。

`toggle-dialogue` 用主题强调和下划线突出 `“…”`、`「…」`、`『…』` 和直双引号中的文字。高亮跨软换行，硬换行后重置；尚未闭合的引号会强调到本段末尾，便于继续输入。它不解析 Markdown，也不修改源码。

`toggle-typewriter` 开关打字机滚动，默认关闭。编辑后光标行尽量位于正文区中部，文稿开头保持自然位置，末尾允许留白。鼠标定位、滚轮、方向键与查找跳转沿用常规滚动，不因重绘反复居中；继续编辑时恢复居中。

`toggle-zen`（专注写作／禅模式）临时只显示当前活动文稿，收起另一窗格和固定面板，正文按已选阅读宽度居中；另一窗格的章节、选区、滚动位置与编辑历史保留。顶栏与窗格编号收起，底部显示字数、真实保存状态、“退出专注”和命令入口；空间紧张时保存状态优先于字数。退出后恢复分栏方向、原偏好和仍有效的来源焦点；切章或停用原模块后返回正文。主动打开的面板以覆盖方式显示，命令和保存始终可达。它不改写布局文件，也不改变聚焦、对话高亮或打字机偏好，重启后不自动进入专注状态。尚未确认的输入框或大纲草稿须先确认或取消再切换。

`toggle-immersion-module` 停用以上写作辅助并退出禅模式，保留文稿、撤销历史与个人偏好。聚焦范围、对话高亮、打字机开关记在工作区配置；显示效果不参与保存。位置与高亮复用当前修订和宽度的排版缓存，仅为可见字素生成样式，没有持续动画。

## 导入已有手稿

F1 → `import-manuscript`，输入 `.txt`、`.md` 文件或目录。默认尝试 UTF-8；解码不匹配时先输入 `utf16le`、`utf16be` 或 `gb18030`（含 GBK）确认来源编码，再预览。`import-encoding` 可在预览时重新选择编码。一次导入对所有正文使用所选编码，混合编码目录请先按编码分批；不猜测编码、不用替换字符掩盖非法字节。正文不能含 NUL；UTF-8/UTF-16 的 BOM 作为编码标记移除，原始字节另存保留。

预览显示卷章顺序、标题及所选章节的原文片段。↑↓ / PageUp / PageDown 或滚轮浏览，鼠标点击选择；Enter 后输入尚不存在的新作品目录才开始创建，Esc 取消。扫描与新作品写入在后台进行，每次只运行一个导入任务；扫描可取消，旧结果不会重新弹出。确认后写入期间请等待完成再退出。预览期间正文编辑快捷键停用，可用 F1/Ctrl+P 调整导入编码或保存、退出。确认期间来源发生变化会要求重新预览。当前工作区先正常保存，保存失败则不创建导入作品。

识别 `第…卷`、`第…章/节/回`、Markdown 标题以及桌面 TXT 的 `【卷名】` / `[Volume]`；围栏代码块内的标题不拆章。目录按文件名中的数字自然排序（1、2、10），子目录名用作卷名，无识别标题时使用文件名。识别是轻量规则，任意小说标题未必能自动识别，务必核对预览；可把各章分别放在独立文件后导入。卷标题前后内容可独立形成卷首或前言章节，标题行、空行、缩进和 LF/CRLF 原样保留，不自动排版。

这是正文迁移，不是旧桌面元数据互通。所有来源文件，包括 JSON、随手记和其他未知附带文件，均按字节复制到新作品的 `source-originals/`；`index.json` 记录原相对文件名与副本路径。归档使用稳定随机文件名，重名或保留名称不会覆盖其他内容。旧大纲、历史和附带文件不会自动进入编辑界面。包含 `novelite.json` 的作品目录请使用 `open-project`。

来源和目标不接受符号链接/目录联接路径；目标不得包含 `..`、使用跨平台保留名称、嵌入来源或当前作品，且父目录必须已存在。使用实际目录的完整路径即可。当前单次上限为 4096 个文件、128 MiB 原始总量、32 层子目录；超出时明确拒绝，可分批迁移。

创建新目录后才写正文与原件，清单最后发布。失败只清理本次已写入且未被外部改动的文件，不递归删除其他内容。进程中断可能留下带 `.novelite-importing` 的未完成目录，应用拒绝将其当作完整作品；原始来源仍保留，可用另一个新目录重新导入。若作品已完整创建而最近记录更新失败，会显示新作品路径，可直接打开。`toggle-import-module` 停用模块会取消预览并恢复仍有效的来源焦点。

## 导出章节与作品

F1 / Ctrl+P 搜索以下命令，输入一个尚不存在的新路径。父目录需要存在；导出不会覆盖已有文件，不改变当前作品或写作位置。

- `export-chapter-md`：导出活动章节的原始 Markdown（单篇文稿也可用）。全部空格、换行和源码原样保留；空稿生成空文件。
- `export-chapter-txt`：按正式桌面版规则处理标题。空白章节输出章节名和换行；开头 Markdown 标题转成纯文本标题，去掉紧接的一行空行，再保留后续正文；正文已经以章节名开头时原样输出，否则添加章节名。不执行段落排版或标点修复。
- `export-book-txt`：先输入本次导出的作者（留空为“佚名”），再输入新 TXT 路径。使用当前书名及卷章顺序，包含空章节，不包含回收区。当前作品格式尚无作者字段，本次作者不会写回元数据。
- `export-project`：导出可直接打开的 TUI 作品目录，保留作品身份、卷章、大纲、目标、回收区、已有历史、冲突备份及未知附带文件。它是作品副本，不是旧桌面版的完整互通格式；会话撤销记录、最近位置、终端偏好和写锁不打包。

文字导出读取当前文稿修订；内存中的文稿先取副本，其他章节在后台读取。确认后的继续输入不会改写已经取得的正文副本。全书读取和输出写盘在后台执行，状态栏显示处理中、已完成或失败；不要把“处理中”当成已导出。每次只运行一项导出，完成前暂不退出或切换作品，仍可编辑正文。目录导出与导入共用新目录发布及失败清理规则；强制中断遗留的未完成目录不会作为完整作品打开。

TXT/Markdown 只包含正文及相应标题，不含大纲、历史和附带文件；需要这些内容时选择作品目录。目录来源最多 4096 个普通文件、128 MiB、32 层，超出时明确失败；不经过符号链接或目录联接。导出目录应位于原作品之外。`toggle-export-module` 可开关导出模块，已确认的写入完成后才能关闭。
