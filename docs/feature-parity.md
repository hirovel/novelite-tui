# 正式版功能对齐

基准为桌面版 [v1.0.4](https://github.com/hirovel/novelite/releases/tag/v1.0.4)，源码提交 `80a54c819bd70fac378737dbed5974fa19f0c0b3`。下表是 TUI 首版的范围与验收要求，不作为完成状态清单；“对齐”指写作能力，不要求复制桌面视觉。实际验证结果单独记录。

| 正式版能力 | TUI 决策 | 验收要点 |
| --- | --- | --- |
| 作品书架与切换 | 保留，以最近作品列表/文件夹打开呈现 | 切换保存所有脏文稿，不混用作品状态 |
| 卷章创建、改名 | 保留 | ID 稳定，名称冲突明确处理 |
| 卷章排序、跨卷移动、章节复制 | 保留 | 排序与磁盘映射一致，中断可恢复 |
| 前后章、标题跳转 | 保留 | 跳转不丢未保存内容，恢复位置 |
| 自动章节编号 | 保留为显式命令 | 说明范围，编号变更可恢复 |
| 回收区与章节恢复 | 保留 | 误删可恢复，不依赖临时撤销 |
| 章节大纲、目标 | 保留 | 大纲是独立元数据，不混入正文 |
| 灵感备忘/随手记 | 不提供独立界面 | 完整迁移时保留或导出旧数据 |
| 章节与全书字数 | 保留 | 样例计数一致，输入时不全书扫描 |
| 章节查找替换 | 保留 | 范围明确，整章替换一次撤销 |
| 全书搜索 | 保留 | 文本与标题匹配、上下文、可取消、修订校验 |
| 命令面板 | 保留并作为基础入口 | 全部功能可发现，能力降级仍可达 |
| 自定义快捷键/速查 | 保留 | 检测内部冲突，不宣称可接管系统保留键 |
| 左右/上下双编辑分屏 | 保留 | 两边可编辑；同章一致，异章分别保存 |
| 分屏焦点切换与交换 | 保留 | 光标和选区跟随正确文稿，隐藏时不丢状态 |
| 撤销重做 | 保留 | 文稿级事务，切布局或关面板不清空 |
| 自动保存 | 改为原生文件持久化 | 修订准确，失败明确，重开内容正确 |
| 章节历史快照 | 保留并自动建立恢复点 | 恢复前备份，跨会话可用，保留策略明确 |
| 外部文件变化 | 保留并明确冲突行为 | 干净时自动载入，双方修改保留两份 |
| TXT/Markdown 导入、卷章识别 | 保留 | 预览识别结果，原文件不被改写 |
| 全书 TXT、章节 TXT/Markdown 导出 | 保留 | 标题处理显式，正文排版不被隐式规范化 |
| 段首缩进、空行整理、去缩进 | 保留为手动命令 | 当前章节范围，一次撤销 |
| 标点修复、中英文间距 | 保留为手动命令 | 不在保存或导出时自动改正文 |
| 成对引号/括号辅助 | 保留，可开关 | 中文输入法不重复配对，退格行为明确 |
| 段落/句子/邻近行聚焦 | 以终端配色/样式表达 | 仅改变显示，低色彩模式仍可用 |
| 打字机滚动 | 保留，可开关，默认关闭 | 输入行定位稳定，鼠标移动不突跳 |
| 对话台词高亮 | 保留 | 仅显示效果，增量计算与中文引号测试 |
| 禅模式 | 保留 | 临时隐藏周边模块，退出恢复布局 |
| 主题与设置 | 三种风格可选，模块可组合 | 重开记忆，配色与布局分离 |
| 字体、字号、精细行距 | 交给终端；应用调宽度与留白 | 不显示无法执行的 GUI 排版选项 |
| 动态背景/光标动画 | 不移植为核心功能 | 字符光标与终端渲染即可完成写作 |
| 插件贡献机制 | 内置模块 Interface | 统一命令、面板、状态、生命周期 |
| 桌面自动更新 | TUI 独立发行，由 Homebrew 更新 | 不共用桌面 latest；升级保留稿件与偏好 |

## 互通边界

同一文件格式是目标；桌面 v1.0.4 仍有 WebView 本地存储，不能直接宣布其已与 TUI 安全共享作品。首版导入/导出正文，完整元数据迁移与共同写锁需桌面端后续适配。交替编辑不等于允许两个客户端同时写入。
