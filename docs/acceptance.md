# 本地性能与体验验收

[规格](spec.md)定义行为，本文件定义证据。当前无 TUI 实现和测试结果。用户已确认从工作区会话入口验证可见行为，本阶段只执行本地测试。

## 验证策略

主要测试从打开作品、输入、命令、切换窗格、观察状态和关闭会话开始。终端/文件系统可替换为受控 Adapter，注入延迟、错误和能力缺失；真实文件与子进程恢复测试补充平台合同。

真实本地终端验证鼠标、系统复制粘贴、中文输入法和最终显示。当前环境为 Windows，不为了本轮任务安排远程 Mac 或云端兼容矩阵。其他平台保持待验证；任何“已支持且验证”的声明必须附对应本地证据。

## 性能基线与预算

用户确认的规模为全书 100 万字、单章 10 万字、双窗格同时编辑。规模是验收基线，不是文件硬上限。

下列数字是首轮工程目标，尚未测量。先记录实际本机硬件、系统、终端、文件系统、字体、窗口尺寸、构建提交和 Release 模式，再建立可重复基线。

| 项目 | 初始目标 | 测量边界 |
| --- | --- | --- |
| 输入响应 | p95 ≤ 16ms，p99 ≤ 33ms | 应用收到已提交字符到对应终端输出完成，不含 IME 候选和屏幕扫描 |
| 交互帧 | p95 ≤ 16ms | 双窗格滚动、选区和布局变化的排版/绘制/输出 |
| 温启动 | ≤ 500ms | 进程启动到上次章节可编辑；冷启动单列 |
| 章节切换 | 热缓存 ≤ 100ms，冷读取 ≤ 300ms | 切换到 10 万字章节的可编辑帧 |
| 空闲 CPU | 平均 < 1% 单核 | 空闲 60 秒，分别记录应用和终端进程 |
| 应用内存 | 稳态 RSS ≤ 150 MiB | 百万字作品、两个不同的 10 万字章节、10 MiB 编辑历史负载；峰值单列 |
| 普通自动保存 | p95 ≤ 200ms | 单个 10 万字章节在本机文件系统持久化；双章同时保存另列 |

机器较慢时不掩盖结果；报告瓶颈和目标调整依据。不能换硬件或变更统计口径来伪装优化。内部计时不代表实际屏幕可见延迟，录像/实际观察作为单独证据。

## 语料与步骤

虚构语料可重复生成，覆盖 1 万、10 万和 100 万字作品，包含 2 万字无硬换行段落、中文标点、emoji ZWJ、组合字符、ASCII、制表符、空行、CRLF 和 Unicode 文件名。另用超出基线的作品验证响应与安全失败，不把通过规模当上限。

在 80×24、120×40、160×50 执行固定编辑序列；预热后每类响应至少 1,000 次，记录 p50/p95/p99/max。启动分别测冷/温至少 10 次。保留原始数据、峰值内存、CPU、帧数与输出字节数。

分别测试同章双窗格、异章双窗格和输入期间全书搜索/自动保存。相同基准比较优化前后，不依赖主观“感觉流畅”。

## 必测边缘情况

- 同章两个窗格交替编辑、撤销、关闭一个窗格，再保存重开；两边不产生独立冲突版本。
- 两个不同章节都有未保存内容时手动保存/退出，逐个校验外部预期正文。
- 后台旧保存完成时已有新输入，不能显示全局已保存。
- 窗口缩小到无法分屏再恢复，不丢视图位置或焦点；三种风格与两种分屏方向都覆盖。
- 自动刷新遇到外部文件删除、非法编码或清单损坏，保留可恢复本地状态并提示。
- 冲突选择前磁盘再次变化，不按过期版本覆盖。
- 磁盘满、只读目录、文件占用、写入失败、临时文件残留、第二实例、路径越界和名称冲突。
- 编辑器选区与终端选区分别复制；无鼠标、无系统剪贴板、无粘贴分隔时反馈准确。
- 原始正文含转义字符，不在渲染或粘贴时变成终端控制命令。
- 格式化和快照恢复前保留恢复点；保留策略不删除手动标记点或未持久化内容。
- 卷章改名/移动/回收在结构事务各阶段终止，重开无悬空映射或截断正文。

## 持久化证据

预期文本保存在被测会话以外，由测试控制进程记录；重启后从文件和会话读取实际文本比较。不能让测试与实现读取同一份缓存作为双方结果。

在写临时文件、刷新、替换、清单提交等阶段终止子进程。恢复须为完整旧修订或新修订；正常退出后的最后输入必须完整。强制终止测试明确记录最后持久化修订后的损失窗口。

平台原子替换必须使用真实本地文件系统验证，受控 Adapter 的通过不能替代该结果。格式迁移失败保留原数据，未知新格式拒绝写入。

## 本地记录模板

每条结果记录：构建提交、命令、硬件/系统/终端版本、字体/尺寸/输入法、能力和配置、步骤、预期、实际、耗时与证据位置。默认状态为待验证，不预填“通过”。

未测终端可以列为设计目标；没有本机运行记录不能列入已验证列表。纯合成输入不能证明 IME 正确，headless 帧快照不能证明鼠标命中和系统剪贴板正确。

## 交付门槛

本阶段交付规格、交互设计、功能对齐和验收方案；只检查文档一致性与链接，不宣称应用测试通过。进入实现后，每个里程碑附用户路径证据。正式发行前才验证安装/升级/手稿保留，当前不创建发行包。
